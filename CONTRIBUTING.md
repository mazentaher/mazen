# Contributing

Thanks for helping improve this cybersecurity learning portfolio.

## Workflow

1. Create a focused feature branch.
2. Make small, understandable commits.
3. Add or update tests when behavior changes.
4. Run the test suite locally with `python -m unittest discover -s tests -v`.
5. Open a pull request against `main`.

## Security

Only contribute defensive, educational functionality for systems and data you are authorized to use. Never commit credentials, tokens, private keys, or real sensitive logs.

## Code quality

Prefer Python standard-library solutions where practical, clear error handling, and documentation that explains safe usage.
