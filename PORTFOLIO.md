# Mazen — Cybersecurity Portfolio

## About

Hands-on learning portfolio focused on cybersecurity, networking, Linux, Python, and defensive security operations.

## Featured Projects

### 🔎 SSH Log Analyzer
Analyzes authentication logs and highlights repeated failed SSH attempts.

### 🔐 File Integrity Monitor
Uses SHA-256 baselines to detect added, removed, or modified files.

### 📊 Local Security Dashboard
Visualizes authentication events from synthetic local data.

### 🐧 Linux Security Lab
Covers permissions, ownership, processes, authentication logs, and safe evidence collection.

### 🌐 Networking Security Lab
Covers IPv4 addressing, DNS, NAT, TCP/UDP, and defensive networking concepts.

### 🔑 Password Strength Checker
Educational password-policy checker that does not store or transmit passwords.

## Engineering Practices

- Feature branches and pull requests
- Unit testing
- GitHub Actions CI
- Security documentation
- Roadmap-driven development
- Safe, authorized lab methodology

## What This Portfolio Demonstrates

The goal is to demonstrate practical problem solving: taking a security concept, building a small tool, testing it, documenting it, and reviewing the change through a real Git workflow.

> All projects are intended for authorized defensive learning and local lab use.
