# Networking Security Fundamentals

## IPv4

An IPv4 address identifies an interface using 32 bits, commonly written as four decimal octets.

## NAT

Network Address Translation allows private addresses to share connectivity through a translating device. It is not, by itself, a complete security boundary.

## DNS

DNS maps names to IP addresses and is an important source of security telemetry.

## TCP vs UDP

TCP provides connection-oriented delivery; UDP is connectionless and has lower protocol overhead.

Practice these concepts in a local lab and use only networks you are authorized to administer.
