# Security Labs

This portfolio uses small, defensive exercises to build practical skills.

## Current labs

1. SSH authentication log analysis
2. SHA-256 file integrity monitoring
3. Password policy education
4. Local security dashboard

## Safe lab rules

- Use only systems and data you are authorized to inspect.
- Prefer sample or synthetic data for demonstrations.
- Never commit credentials, tokens, private keys, or sensitive logs.
- Keep experiments local and reversible.
