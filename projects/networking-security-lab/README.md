# Networking Security Lab 🌐🛡️

A defensive networking fundamentals lab using local and synthetic data.

## Topics

- IPv4 addressing and subnet concepts
- DNS and name resolution
- NAT and private addressing
- TCP/UDP basics
- Reading simple connection metadata

## Safe practice

Use a local VM or your own lab network. Examples are designed for learning concepts rather than probing systems you do not own or have permission to test.
